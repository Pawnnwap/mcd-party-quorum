# 组局卡 / 参数清单 / 降级卡 模板

> 占位一律用方括号 `[字段名]`。禁用花括号占位与尖括号占位。
> **卡内所有数值由脚本注入**（`../scripts/quorum_calc.py` 与 `../scripts/money.py`），
> 模型只填描述性字段，且描述文案里不得出现任何数字。
> 渲染完成后必须再跑一次 `../scripts/money.py --check` 做裸值自检。

## 1. 组局卡模板

    🍔 麦当劳 · [活动名] · 组局卡
    [selling 官方卖点原文，逐字引用]

    📍 [城市] · [门店名]（[门店地址]，距你 [距离文案]）
    🗓  [日期]（[星期]）[开始时间]–[结束时间]（约 90 分钟）
    👥 已确认 [已确认人数] 人 · 最少 [起订人数] 人 → [成团结论]（上限 [人数上限]，余位 [余位]）
    💰 人均 [人均金额] · [已确认人数] 人共 [合计金额]（每加 1 人 +[人均金额]）
    ⏳ 预订死线（按官方文案「提前 [提前天数] 天」估算）：[死线时间] → 还剩 [剩余时长]
       （advisory 提示性）实际可约日期与场次请以预约页面 / 门店确认为准
       （仅当已过死线时追加）已过官方文案建议的提前预订期，是否仍可预订请以预约页面为准

    ⚠️ 官方文案写 [文案日期区间]，接口显示 [接口日期区间] 可约，以门店最终确认为准
    ✅ 参与方式：回复 +1，凑满 [起订人数] 人我发起预订
    📌 [年龄门槛] 可参加；退改需提前 [退改天数] 天；[不适用门店类型] 不适用
    📌 本技能不会代你下单；下单参数请在你自己的 MCP 客户端确认后执行

字段来源约束：

- `[成团结论]` 由脚本给出：`need > 0` → 「还差 [need] 人发车」；`need <= 0` → 「已成团，
  可发车」。
- `[人均金额]` 与 `[合计金额]` 必须来自 `format_cny()`，**禁止出现裸分数值**。
- `[剩余时长]` 由脚本按「场次日期减提前天数个自然日，时刻 23:59:59」计算，禁用本地时间。
- 已过死线**不是**拒绝出卡的理由，只在卡面追加一句标注。

## 3. 下单参数清单模板

    | 字段 | 值 | 来源 | 说明 |
    |---|---|---|---|
    | code | [城市编码] | api | 来自 query-party-city |
    | count | [数量] | user | 用户确认 |
    | dateStr | [日期] | api | 来自 query-party-store-date |
    | id | [场次ID] | api | 来自 query-party-store-session |
    | leftNum | [余位] | api | 来自 query-party-store-session |
    | partyType | [1 或 2] | user | 1 包场 / 2 拼团，用户拍板 |
    | skuId | [SKU ID] | api | 来自 mall-product-detail 的 skuList |
    | spuId | [活动ID] | api | 来自 mall-points-products |
    | storeCode | [门店编码] | api | 来自 query-party-store |
    | timeEnd | [结束时间] | api | 来自 query-party-store-session |
    | timeStart | [开始时间] | api | 来自 query-party-store-session |

    来源只能是 api 或 user；agent_invented 一律被 `../scripts/order_params.py` 拒绝。
    📌 本技能不会代你执行：请在你自己的 MCP 客户端确认后执行下单。
